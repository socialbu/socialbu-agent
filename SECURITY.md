# Security

## Report a vulnerability

Do not open a public issue for a suspected vulnerability or include credentials, access tokens, customer data, or private account details in GitHub.

Email `support@socialbu.com` with a concise description, reproduction steps, affected URLs or client versions, and the impact you observed. Remove secrets and personal data from screenshots and logs.

## Credential handling

The SocialBu MCP server uses OAuth. Complete authorization in the SocialBu browser flow and store credentials only in the MCP client's secure credential storage.

Never commit SocialBu credentials to this repository or place them in prompts, issue reports, analytics, logs, screenshots, or plugin manifests.
